Welcome to the Run Configuration Editor

To get started, select the following from the dropdown menus:

  1. The DAQ version you would like to use.
  2. Once this is selected, the session you would like to access.

The configuration loads as soon as a session is selected.

The include/exclude, map and adjustable attribute panels described below are not yet available in the web UI.

Include/Exclude Panel

These tabs contain everything in the detector that can be toggled on/off. To toggle an object on/off press its button. If a parent of the object is switched off, the button will not be pressable. To see these relationships you can use the map panels.

Map Panels

The Configuration view is an overview of a large subset of objects within the detector. It gives you a global view of what's currently included/excluded.

The System Maps give you maps of elements in the include/exclude panel. This can tell you exactly what the panels are turning on and off.

Adjustable Attributes

Adjustable attributes are things we want to set the value of before the run, for example, trigger rates.

Creating a Configuration

Once you're done modifying the configuration, press "Create Run Configuration". This generates a configuration file and shows the command to use it with DRUNC.

Resetting

"Reset to Default" reloads the selected session, discarding any changes you have made.
